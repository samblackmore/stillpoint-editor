Random level

Generate a level from a seed — share the seed to share the level.

The generator is a port of the Unity LevelFactory; the config lives in generator-config.json.

Levels

Hand-made levels from the Unity game, loaded as JSON from the repo. Tap a cell to preview a wall, tap it again to place it — every character's path updates live. Tap GO, or tap the same cell again, to place it. Tap a wall to preview removing it.

Want to make one? Open the level editor — it exports the same JSON format.

Stillpoint HTML prototype — a port for fast prototyping and playtesting. Rules ported from the Unity game (pathfinding, turn flow, generator); abilities, flood and fog are not ported yet — see README.
